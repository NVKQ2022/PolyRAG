# PolyRAG Adapters & Bridges 🔌

The `polyrag.adapters` module contains bridges to popular AI and data ecosystems, enabling you to reuse external tools without compromising PolyRAG's lightweight, decoupled core.

---

| Adapter Guide | Ecosystem | Purpose |
